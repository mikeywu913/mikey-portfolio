## Overview

Hi, I'm MIKEY, also known as Wu Biaozhen. I work across creative strategy, directing, photography and editing. Sometimes, something I haven't quite found the words for turns into a song.

With fellow students at the University of Malaya and the team at IMA, I made [The Voice of Penny](https://mikeywu913.github.io/mikey-portfolio/?work=voice-of-penny), a short film about a girl finding her voice through drawing. I also wrote [The Fire is On Us](https://mikeywu913.github.io/mikey-portfolio/?work=the-fire-is-on-us), putting a few questions about where we're headed into music. The light and small moments I couldn't walk past live in my [photography archive](https://mikeywu913.github.io/mikey-portfolio/?archive=photography).

I like taking an idea from “this could work” to something you can actually watch, hear or hold. This is a collection of those attempts, with more on the way. Have a look around. Feel free to leave the music on.

<summary>About this website</summary>

A Chinese–English portfolio built with React, Vite and Motion, published through GitHub Pages. Photographs open at full resolution, videos play in their detail views, and music plays one track at a time.

Run locally:

```sh
npm ci
npm run dev
```

Check before publishing:

```sh
npm run check:media
npm run lint
npm run build
```

The README's hierarchy and navigation take inspiration from [Brittany Chiang / v4](https://github.com/bchiang7/v4) and [developerFolio](https://github.com/saadpasta/developerFolio). The introduction is written around my own work and experience.

</details>
