## Overview

嗨，我是 MIKEY，吴骉震。做创意策划，也做导演、摄影和剪辑；偶尔一句没说出口的话，会变成一首歌。

我和马来亚大学、IMA 的伙伴们一起拍了 [《佩妮寻声记 / The Voice of Penny》](https://mikeywu913.github.io/mikey-portfolio/?work=voice-of-penny)，讲一个女孩如何通过绘画找到自己的声音。也写了 [《The Fire is On Us》](https://mikeywu913.github.io/mikey-portfolio/?work=the-fire-is-on-us)，把一些关于去向的疑问唱了出来。至于日常里舍不得错过的光和瞬间，都放进了[摄影档案](https://mikeywu913.github.io/mikey-portfolio/?archive=photography)。

我喜欢把一个想法从「好像可以」做到「真的出来了」。这里是其中一些结果，还在继续更新。欢迎随便逛逛，音乐可以开着听。
